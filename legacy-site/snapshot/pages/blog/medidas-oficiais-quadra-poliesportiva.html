Medidas Oficiais da Quadra Poliesportiva: Normas e Padrões

Dimensões oficiais por modalidade, área de segurança e requisitos técnicos para construção de quadras esportivas.

Conhecer as medidas oficiais da quadra poliesportiva é fundamental para garantir que seu projeto esteja em conformidade com as normas esportivas e técnicas. Um espaço com dimensões corretas proporciona segurança, melhor desempenho atlético e valorização do imóvel.

Dimensões Padrão da Quadra Poliesportiva

A quadra poliesportiva é projetada para abrigar múltiplas modalidades em um único espaço. As dimensões variam conforme o uso pretendido:

Tipo de Quadra Comprimento Largura Área Total
Oficial (CBF/CBV/CBB) 28m 15m 420m²
Poliesportiva Padrão 20m 10m 200m²
Quadra Média 18m 9m 162m²
Quadra Compacta 16m 8m 128m²
Quadra Mini 12m 6m 72m²

Medidas por Modalidade Esportiva

Futsal

  • Dimensão mínima: 25m x 16m
  • Dimensão máxima: 42m x 25m
  • Padrão recreativo: 20m x 12m
  • Área de segurança lateral: 1m mínimo

Vôlei

  • Quadra oficial: 18m x 9m
  • Com zona livre: 24m x 15m
  • Altura mínima livre: 7m
  • Linha central: Obrigatória sob a rede

Basquete

  • Quadra oficial FIBA: 28m x 15m
  • Com zona livre: 34m x 21m
  • Altura mínima livre: 7m
  • Linha de 3 pontos: 6,75m do aro

Handebol

  • Quadra oficial: 40m x 20m
  • Com zona livre: 44m x 22m
  • Área do gol: Raio de 6m
  • Linha de 9 metros: Linha tracejada a 9m do gol

Requisitos Técnicos da Norma ABNT

A ABNT NBR 15842 estabelece os requisitos para instalações esportivas:

  • Nivelamento: Tolerância máxima de 3mm por metro linear
  • Caimento para drenagem: 0,5% a 1% nas laterais
  • Área de segurança: Mínimo 2m em todas as extremidades
  • Altura livre mínima: 7m para quadras cobertas
  • Iluminação mínima: 300 lux para uso recreativo; 500 lux para competição

Marcações da Quadra Poliesportiva

As linhas da quadra poliesportiva devem seguir especificações precisas:

  • Largura das linhas: 5cm
  • Cores distintas: Cada modalidade deve ter linhas em cor diferente
  • Pintura: Tinta específica para piso esportivo, antiderrapante
  • Contraste: As linhas devem contrastar com a cor do piso
