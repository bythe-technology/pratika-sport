# Pratika Sport

Novo site institucional da Pratika Sport, produzido e mantido pela BYTHE.

## Estado atual

A primeira versão pública é uma página de manutenção com os principais canais de contato. A cópia técnica do site anterior está preservada em `legacy-site/` para orientar a reconstrução e a migração de SEO.

## Segurança de migração

- Não alterar o domínio principal antes da homologação.
- Preservar as 47 URLs canônicas ou configurar redirecionamentos 301 equivalentes.
- Não indexar a página temporária de manutenção.
- Não remover o inventário histórico até o fim da migração.
